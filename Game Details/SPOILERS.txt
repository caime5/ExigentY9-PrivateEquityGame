Opening any file in this level will de-mystify the experience. The single player game can be played by running the file on the outer level of the folder.
If you wish to run the multiplayer experience, have the organizer run XGNPhysicalVsn
If you truly wish to pull back the curtain, the following files do the following:
  XGNPhysicalVsn is the save-load, year updating, and list of companies for both the physical and terminal games.
  XGNPhysicalVsnTests are checksums to ensure that the companies were not mistyped; among other things.
  XGNTerminalGame is the file run that allows for the experience to work with 1 player.

If you wish to change the game:
  Ensure that "Original Creator: Carlos Isaias Mendoza (carisamen157@gmail.com)" is in the header.
  To add companies, then it may be wise to add it in either the terminal or physical version; based on needs.
  It is possible, though a headache, to restrict a company from being bought/sold based on year count. I leave that to any future adapter in case they wish to do so.
  Have fun and do not get mad as you code.
